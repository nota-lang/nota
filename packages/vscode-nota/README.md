# Nota for VS Code

Language support for the [Nota](https://github.com/nota-lang/nota) document language:

- Syntax highlighting for `.nota` files — an instant TextMate first paint, upgraded by
  reader-accurate semantic tokens once the language server is running.
- Diagnostics, hover, completion, go-to-definition, find-references, and rename, driven by the
  Nota language server (Volar) over each document's typed virtual module.

The extension bundles the language server and the wasm build of the Nota reader — no other
installation is required.
